# EigenNoise Regularization for Deep Learning

## Overview

This project explores regularization in convolutional neural networks using CIFAR-10. The notebook contains baseline and L2-regularized autoencoder experiments, EigenNoise-based autoencoder experiments, small-subset CNN comparisons, and an EigenNoise-based residual CNN with spectral regularization.

## Dataset

CIFAR-10 contains 60,000 color images across 10 classes. The final residual CNN experiment uses the full dataset, with 50,000 training images and 10,000 test images. Earlier experiments use a smaller subset for training and evaluation.

## Methods

- **Baseline autoencoder:** Convolutional image reconstruction using mean squared error.
- **L2-regularized autoencoder:** Adds an L2 penalty to convolutional weights.
- **EigenNoise autoencoder experiments:** Explore an additional perturbation-related loss and compare singular-value distributions.
- **Baseline and L2 CNNs:** Compare classification performance on a smaller CIFAR-10 subset.
- **EigenNoise residual CNN:** Uses residual blocks, batch normalization, data augmentation, and a singular-value-based spectral penalty.

## Main result

The saved notebook reports **85.15% test accuracy** for the EigenNoise-based residual CNN on the full 10,000-image CIFAR-10 test set.

The notebook also reports the following average condition-number diagnostics:

| Model | Average condition number |
|---|---:|
| Baseline | 2.131196 |
| EigenNoise | 4.4509764 |

Condition numbers are descriptive diagnostics and do not, by themselves, demonstrate better generalization.

## Results

The `Eigennoise_results/` folder contains:
- `results_summary.json`
- `classwise_accuracy.csv`
- `classification_report.txt`
- `README.md`

The numbers were extracted from the saved notebook outputs and were not generated by a new training run.

**Evaluation caution:** The notebook reports an adjusted accuracy of 86.43% after calculating class weights from true test-label counts and predicted test-label counts. Since this uses test-set information to adjust predictions, do not report it as the primary unbiased test accuracy.
